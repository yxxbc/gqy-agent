# 12 · 备份、迁移与更新

> ⚠️ **临时版本提示**：本文档由 DeepSeek 根据当前 顾清影 源码逐行整理，属于临时参考版本；正式版文档仍在施工中，内容可能与最新代码存在出入。请以 `gqy -h`、`gqy config`、仓库 README 及源码为准。

## 1. 导出：`gqy export`

把当前安装打成 `.tar.gz`，权限 0600：

```bash
gqy export                         # 默认：配置、会话历史、记忆、知识库原文、用户资源
gqy export --index                 # 额外带知识库向量索引
gqy export --platforms             # 额外带平台聊天历史
gqy export --all                   # = --index + --platforms
gqy export --no-secrets            # 清空 API key 与令牌，导入后自己补
gqy export --dry-run               # 只看清单和体积，不写文件
gqy export --force                 # 覆盖同名归档
gqy export 自定义路径.tar.gz
```

默认文件名：`gqy-export-<主机名>-<时间戳>.tar.gz`。

### 包含什么

- 配置、人格、身份、用户技能/脚本/表情等资源。
- 会话历史与记忆（数据库导出）。
- 知识库原文（默认**不含**很大的向量索引；可 `gqy kb embed` 重建）。
- `--platforms` 才带 QQ 等平台的聊天历史。

### 不含什么

- 缓存、日志、spill、一次性本机状态。
- 默认知识库本体（会随新版本/`update-default-kb` 重新来）。
- WebUI 主题库 `config/webui-themes/`（单文件的 `config/webui-theme.css` 会带上）和 iMessage 桥接的 `config/imessage.json`、`state/imessage-*.json`，目前不在导出清单（`src/transfer/registry.rs`）里，换机时手动拷。

### 安全警告

- 导出归档是**明文 tar.gz**，默认带 API key/token；程序会在 stderr 警告。
- 别把归档发到公开场合；需要分享就加 `--no-secrets`。

## 2. 导入：`gqy import`

```bash
gqy daemon stop                 # 必须先停 daemon（它占着数据库）
gqy import gqy-export-*.tar.gz
gqy import 归档 --force          # 覆盖现有数据（先自动备份当前安装）
```

导入前会检查 daemon 未运行；导入完成后会提示备份位置和后续步骤（例如重建 embedding、补 API key）。

## 3. 布局迁移（自动发生）

旧版本用 XDG 路径，新版本统一到 `~/.gqy`：

- 首次启动检测到旧布局时自动迁移；若旧 daemon 还活着，新客户端会暂时沿用旧路径，等新 daemon 接手后完成迁移。
- 迁移是“预检两遍 + 目录 flock + 逐条搬 + 写 marker”的流程；失败不半途写入。
- 资源目录（skills/scripts/prompts/identities/persona-avatars）会从 config 挪到 data，并写 journal 保证可恢复。
- 家目录布局（分层架构阶段 6）：`data/personas` → `personas/`，`data/{skills,scripts}` → `extensions/`，`state/conversation.db` 与 `data/{ledger,artifacts,documents,pictures,shared,identities}` → `home/<管理员>/`（`user-identity.md` 改名 `profile.md`）。标记 `.home-layout-v1` 里写着管理员家目录名（`GQY_ADMIN_USER` → 系统用户名 → `admin`）。`gqy layout` 看计划，`--apply` 手动搬，`--rollback` 搬回去并写 `.home-layout-off` 关掉自动搬家。同样是预检 + journal + 原子移动，daemon 在跑就不搬。

## 4. 更新默认知识库

```bash
gqy update-default-kb
```

- 更新来源：本项目仓库（`yxxbc/gqy-agent` 的 `gqy` 分支）的 `kb/` 目录（09-24 起，不再拉上游的 Shorin Arch 指南）。
- 每天自动检查一次：比较 `kb/` 目录的 tree 哈希而不是提交号，代码提交不会触发提醒；有更新会提示运行上面的命令。
- 需要 `git` 命令；部分克隆 + sparse checkout 只取 `kb/**/*.md`，省流量。

## 5. 升级 顾清影 本体

### Nix（推荐）

```bash
nix profile upgrade gqy-agent   # 出问题：nix profile rollback
```

详见 [18-Nix安装开发与发布](18-Nix安装开发与发布.md)。

### install.sh

再运行一次安装命令就是升级。

升级后 CLI 发现 daemon 还是旧 build 时，会自动重启 daemon 到新 build（比较 `GQY_BUILD_ID`）。

### 源码

```bash
git pull
cargo install --path . --locked   # 要语音再加 --features voice
# 老 daemon 会被新二进制自动替换重启
```

## 6. 发布流程（给维护者）

Actions 页手动运行 `publish-release.yml` 填版本号 → 工作流把 `CHANGELOG.md` 的 `[Unreleased]` 定稿、提交并打 tag → 云端编译 4 个平台发布 Release → 自动回写 `nix/release.json`，完整步骤见 [18-Nix安装开发与发布](18-Nix安装开发与发布.md) §4。

资产约定：字体、模型、默认知识库、系统脚本都装在「前缀/share/gqy/」下，打包时缺一不可（缺失有降级行为，见 [11-数据与目录](11-数据与目录.md)）。
