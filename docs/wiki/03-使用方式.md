# 03 · 使用方式

> ⚠️ **临时版本提示**：本文档由 DeepSeek 根据当前 顾清影 源码逐行整理，属于临时参考版本；正式版文档仍在施工中，内容可能与最新代码存在出入。请以 `gqy -h`、`gqy config`、仓库 README 及源码为准。

顾清影 有四种主要入口：**终端 REPL**、**一次性命令**、**WebUI**、**通讯平台（QQ）**。它们共用后台 daemon 和会话数据库。

## 1. 终端 REPL

### 进入与退出

```bash
gqy             # 普通模式 REPL，每次打开是新会话（第一次会先进新手引导，见 01）
gqy -c          # 回到普通模式上次的会话
gqy --session 名字   # 直接打开指定会话（按名字、编号或 id；开发模式的会话会以开发模式打开）
gqy dev         # 开发预设 REPL，同样默认新会话
gqy dev -c      # 回到开发模式上次的会话
gqy oobe        # 手动再跑一遍新手引导
```

新会话：车道上次那条还一句没说过就直接用它，说过话才新建，反复开关不会攒一堆空会话。`display.repl_replay_turns`（回放轮数）只在 `-c` / `--session` 回到已有会话时生效。

会话还是空的时候是开屏欢迎框：圆角小框里左边是吉祥物，右边是欢迎语（有过对话说「欢迎回来」，全新安装说「初次见面」）、当前目录、`◉ 普通模式 ○ 开发模式 Tab 切换` 和一行提示；框下一行列出最近几个会话。全屏下欢迎框和输入框一起垂直居中、同宽；inline 下欢迎框在输入框上方。画面是静止的，不占 CPU。这时按 **Tab** 在普通 / 开发两条车道之间切（另一条车道当前会话已有回合就新开一条空的）；
第一条消息一发，欢迎框撤掉、模式钉死（中途换模式 = 系统提示词换血 = 缓存作废），`/new` 或 `/reset` 之后又回来。
吉祥物由 `display.mascot` 选：`portrait`（顾清影立绘，默认；kitty 下贴原图，其他终端用半格字符画，终端太矮自动缩小或不画）、`cat`（黑猫字符画）、`custom`（读 `config/banner.txt`，首行可写 `subtitle: 副标题`，`# ` 开头是注释）、`off`。立绘在 16 色终端画不出，自动换黑猫。`display.banner = false` 整个关掉欢迎框；
色深按 `COLORTERM` / `TERM` 自动降级，`GQY_COLOR=truecolor|256|16|none`、`GQY_ASCII=1`、`NO_COLOR` 可手动压。

### 快捷键

| 按键 | 作用 |
|---|---|
| `Enter` | 发送 |
| `Shift+Enter` / `Ctrl+J` | 换行 |
| `Up` / `Down` | 浏览历史输入 |
| `Tab` | 补全斜杠命令；空会话时切换 普通/开发（不弹「已切换到会话」） |
| `Ctrl+V` | 粘贴（图片会变成 `[Image N: 文件名]` 占位符） |
| `Ctrl+L` | 清屏 |
| `Ctrl+C` | 分级：输入框有字先清空草稿 → 有后台任务则询问停任务 → 无任务才退出 |
| `Ctrl+D` | 退出（daemon 里的回合继续跑） |
| `Esc Esc` | 编辑时取消/清空 |
| `Ctrl+W` | 删除一个词 |

### REPL 斜杠命令

REPL 内以 `/` 开头的是控制命令，**不会发给模型**：

| 命令 | 作用 |
|---|---|
| `/help` | 帮助 |
| `/exit` | 退出 |
| `/new [名字]` | 新建会话 |
| `/session [名字或编号]` | 切换会话（弹选择器，选择器内 Ctrl+D 可删） |
| `/rename 名字` | 重命名当前会话 |
| `/delete [名字或编号]` | 删除会话（需确认） |
| `/sandbox [路径或 clear]` | 把当前会话关进某个目录（Landlock 沙盒）：之后的回合只能在这个目录里读写；不带参数查看，`clear` 解绑 |
| `/models [序号|provider/model|default]` | 给当前会话换模型 |
| `/persona [名字]` | 切换人格 |
| `/variant [档位]` | 切换思考档位 |
| `/usage` | 查看本轮/累计 token |
| `/config` | 打开配置 TUI |
| `/undo` | 撤销上一轮并回填输入 |
| `/pop [数量]` | 把最旧的 N 轮移出活跃上下文（归档） |
| `/compact` | 立即压缩当前会话历史 |
| `/history [-l N --raw --no-thinking]` | 看会话历史 |
| `/clear` | 只清屏幕，不碰会话 |
| `/reset` | 清空当前会话上下文 |
| `/reset-memory` | 清空本次会话记下的长期记忆 |
| `/reset-all-memory` | 清空当前人格的全部长期记忆 |
| `/wipe` | 抹掉会话/记忆/群聊上下文等（需确认，不可撤销） |

命令大小写不敏感。**唯一前缀只在 Tab 补全里展开**（`/var` + Tab → `/variant`）；
直接回车必须是完整命令名。以 `/` 开头但不在上表里的输入不是命令，会当成普通
消息发给模型——`/home/shorin/notes.md 这个文件讲了什么` 可以直接发。

> 回车不做前缀展开是有代价换来的：以前 `/n 什么的` 会静默建一个叫「什么的」的
> 会话，`/d 3` 会静默删掉 3 号会话。

### 对话中的状态

- 回复进行中按回车提交**命令**会提示“当前回复结束后才能执行命令”，该命令不会被
  执行也不会排队；普通消息（含 `/` 开头但不是命令的）照常排队，回复结束后自动
  作为追问发送。
- 后台任务会显示在 spinner 条上：类型、job_id、标题、时长。
- 失焦时（如切到别的窗口）回合完成可以发桌面通知。

## 2. 一次性提问

```bash
gqy "帮我解释这个报错"
gqy ask "东京天气"
echo "error log" | gqy --stdin ...   # 内部隐藏参数；一般用 gqy "..." 即可
```

- 默认创建临时会话，结束后删除。
- `gqy "..." -c`：发到终端集成会话（保持上下文）。
- `gqy --session 2 "..."`：发到指定会话（名字、编号或 id）。
- `gqy --stdout "..."`：纯文本输出，无颜色/TUI，适合管道。
- `gqy --debug "..."`：写详细诊断日志。

### 图片输入

在 kitty 等终端粘贴图片，会变成 `[Image N: 文件名]` 占位符；顾清影 会解析路径并调用视觉模型。也支持从管道/剪贴板拿图片。

## 3. 终端 shell 集成

安装 hook：

```bash
gqy fish-init
gqy bash-init
gqy zsh-init
```

效果：

| shell | 效果 |
|---|---|
| fish | 最完整：输入自然语言自动拦截对话，可多行、可复用终端会话 |
| bash / zsh | 单行对话 |

- 安装后会写 hook 文件：fish 在 `$XDG_CONFIG_HOME/fish/conf.d/gqy.fish`；bash/zsh 在 `~/.gqy/config/shell/`。
- 内部协议：hook 先分类（`--shell-classify`，退出码 0/1/2），再拦截（`--shell-intercept`）把自然语言发进终端集成会话。
- 移除：`gqy remove-shell-hook`。
- 终端会话相关命令：`gqy models`、`gqy variant`、`gqy history`、`gqy reset`、`gqy pop`。
- 终端集成会话的模型覆盖持久化在 StateStore，`default` 恢复跟随全局模型池。

## 4. WebUI

```bash
gqy web                     # 默认 0.0.0.0:8300
gqy web --port 9000
gqy web --bind 127.0.0.1    # 只本机
gqy web -p                  # 交互式设密码
gqy web -p 你的密码
gqy web --password-file 文件
```

- `gqy web` 会自动启动 daemon（如果没跑），打印局域网访问 URL 后退出；daemon 留在后台。
- 默认端口被占用时自动换随机端口；指定端口冲突则报错。
- 网页功能：会话列表、模型/思考档位切换、附件上传、SSE 流式输出、提问卡片、Artifact 工作区、控制台（左下角进入：用量统计、设置，以及记忆 / 知识库 / 表情包 / 好感 / 脚本等管理面板），以及「平台」页：按通讯平台分组，QQ 的连接设置、消息记录、群聊管理都在这里。
- 登录：有密码时限流（同 IP 60 秒 5 次失败），成功后种 HttpOnly cookie。
- 多用户（邀请制）：WebUI 永远要登录。第一次访问用内置账号登录（用户名 `gqy`，密码 `GQY520`），会进入「创建管理员账号」这一步，建完号内置账号就失效，以后用这个账号登录。管理员在控制台「账号」页生成一次性邀请码（默认 7 天），朋友在登录页「注册账号」凭码建号。每个人只看到自己的会话，管理员也看不到成员的；成员没有设置页与管理面板，只剩自己的数据统计和账号页。用量按人记账。新成员注册后有三步引导（人格 → 功能 → 认知）：可以创建只属于自己的人格（名字、设定可留空、头像、看板图，功能页只摆真正可选的东西：闹钟/汇率/Arch/API 额度/表情包/生图/记账这几个内置插件按管理员放行的给开关，脚本工具与技能逐个勾；记忆、知识库、技能、MCP、文件读写、视觉分析、搜图、用量查询常开不给关，语音不给成员，外发只有管理员有；落到 `persona.toml` 就是 `plugins.enabled` / `plugins.scripts` / `plugins.skills`，`plugins.mcp` 也可手写），存在 `home/<用户名>/personas/<id>/`，会话按人格分开，随时在账号页切换/编辑/删除；「希望 AI 如何认知你」写进 `home/<用户名>/profile.md`。成员的会话库、知识库、账本各自在 `home/<用户名>/` 里，开了知识库/记账/表情包的成员在控制台有自己的面板。成员在沙盒里：只能读写自己家里的 `workspace/`（外加 /tmp 和系统目录只读），管理员的家和 ~/.gqy 读都读不到；管理员默认不受限，想关就用 `/sandbox <路径>` 把某个会话关进一个目录（见 [16-安全与隐私](16-安全与隐私.md)）。成员也能开 dev 会话，同样关在沙盒里。管理员在设置页「成员账号」里划成员能勾的插件、能否自建人格。没有沙盒、没有按人额度——防君子不防小人。
- WebUI 断线**不会**取消运行中的回合；可点取消或调用取消 API。
- 输入框下方的上下文圆环可以点：弹出分项占用——系统提示词、工具（常驻 / stub / MCP）、技能、压缩摘要、化石化瞬态、消息历史，外加自动压缩缓冲、剩余空间和「占用最多的 5 条」。顶部总数有供应商实测时用实测，分项是本地 o200k 估算，两者之差单列「分词器差异」；用 claude-code / codex / agy 中转时多一行「CLI 自带（推算）」。弹窗里的「立即压缩」与 `/compact` 同一条路，先确认再压，回合进行中不可用。手机上是底部面板。
- 聊天正文里选中一段文字再右键，弹出 顾清影 自己的菜单：**解释**、**翻译**（汉字多就译成英文，否则译成中文，浮窗里可切）、**引用追问**（把选中文字以 `>` 引用插进输入框）、**搜索**（知识库与网页两栏，网页搜索只给管理员）、**复制**。解释和翻译走「设置 → 模型池 → 旁路请求 → 划词解释 / 翻译」那一档模型，带上这段话所在回合的问与答当上下文，口吻是中性说明；结果只显示在选区旁的浮窗里，不进对话、不进记忆、不留历史，关浮窗即中断。浮窗按住标题栏可以拖动，拖过或点「钉住」后点别处不会关，可以再选别的词开第二个；长链接、路径、报错原文在浮窗内折行，代码块在块内横向滚动。要浏览器原生菜单就按住 Shift 再右键。手机上选区停稳后在下方浮一条工具条。
- 回复里生成或改写过文件，气泡底部会挂一排产物小签：类型徽标 + 截断的文件名（悬停看全名），点小签在右侧工作区打开，点旁边的下载按钮直接落盘。关掉工作区、或在资源菜单里「移除」过的产物，都能从小签再调回来；刷新页面后小签照旧在。
- 工作区里的图片：滚轮以指针为中心缩放，按住拖动平移，双击在「适应」与「原始尺寸」之间切换；点一下工作区后可用键盘 `+` `-` `0`。
- 正文里的 ` ```svg `、` ```html `、` ```mermaid ` 代码块会画成图，块头可在「预览 / 源码」之间切换，选过的方式对同一段源码保持。svg 按图片显示；html 和 mermaid 放进与 Artifact 预览同样的密封沙箱里运行——脚本能跑、按钮能点，但读不到登录状态和主界面、也连不了外网（页面里可以引内置的 `/vendor/echarts/…`）。html 与 mermaid 在回复生成期间先显示「回复完成后渲染」，完成后才画；mermaid 按当前主题配色，切换主题后已画出的图要重进会话才换色，语法写错会在框里显示报错原文。

## 5. QQ / OneBot

概览见 [13-QQ与通讯平台](13-QQ与通讯平台.md)。最简步骤：

1. 准备一个 OneBot v11 实现（项目默认针对 NapCatQQ 适配）。
2. `gqy config` → IM 平台 → QQ → 打开 enabled，填 access token、管理员 QQ 号。
3. 反向 WS 默认监听 `:8300/onebot/v11/ws`（当前 0.4.x 主要实现反向 WS，顾清影 做服务端）。
4. 私聊远程操作：给 顾清影 发消息即可（建议配私聊白名单）。
5. 群聊：配触发关键词、白名单/游客限流、群管理权限。

QQ 端斜杠命令：`/reset`、`/reset all`、`/wipe`、`/reset-memory`、`/reset-all-memory`、`/stop`、`/models`（前缀默认 `/`，可改）。

## 6. 后台服务 daemon

```bash
gqy daemon start
gqy daemon status
gqy daemon logs            # 跟随日志
gqy daemon logs -n 200
gqy daemon logs request    # 录制并实时监控每个 LLM 请求（Ctrl+C 关闭）
gqy daemon restart
gqy daemon stop
```

- daemon 是“统一后台”：Web 服务器、QQ 平台、LLM 回合、后台任务、闹钟之外的长期状态都由它持有。
- REPL 远程模式优先把回合交给 daemon：你退出 REPL，回复仍在 daemon 继续；重进可接上。
- daemon 与前端通过 Unix socket + JSON 帧 IPC 通信（版本 3，最大帧 24 MiB）。
- 若检测到二进制是旧 build，CLI 会尝试重启 daemon，避免协议/数据库不匹配。
- 环境变量 `GQY_DIRECT`（非 0）可让 REPL 走直连模式，不依赖 daemon；直连少部分命令不可用。

## 7. tool-call 工具桥

```bash
gqy tool-call --list
gqy tool-call get_weather '{"location":"Tokyo"}'
gqy tool-call get_weather --stdin <<<'{"location":"Tokyo"}'
gqy tool-call --describe get_weather
```

- 以当前会话身份调用 AI 工具，供 shell 脚本编排。
- 可用 `GQY_SESSION` 指定会话；内层调用在 daemon 侧会话工作区执行，不继承你 shell 的环境变量和 cwd。

## 8. 通知

桌面通知 best-effort：Linux/BSD 用 `notify-send -a GQY`，macOS 用 osascript，Windows 用 PowerShell。失败静默，不影响主流程。配置在“全局设置 → 通知”。
