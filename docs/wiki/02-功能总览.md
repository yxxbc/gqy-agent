# 02 · 功能总览

> ⚠️ **临时版本提示**：本文档由 DeepSeek 根据当前 顾清影 源码逐行整理，属于临时参考版本；正式版文档仍在施工中，内容可能与最新代码存在出入。请以 `gqy -h`、`gqy config`、仓库 README 及源码为准。

顾清影 的能力来自“大模型 + 一堆可被模型调用的工具 + 长期记忆/会话状态”。下面按生活场景分类，帮你快速知道“我能让 顾清影 干什么”。

## 两种模式

| 模式 | 启动方式 | 特点 |
|---|---|---|
| Normal 普通模式 | 裸 `gqy` | 顾清影 人格、表情包、记忆、玄学、游戏、聊天等全部功能 |
| Dev 开发模式 | `gqy dev` | 隔离的极简配置：无人格、无闲聊插件，只有命令执行/任务/文件编辑等开发相关工具，最大程度发挥模型编码能力 |

两个模式的数据、记忆和配置相互隔离。

## 功能地图

### 聊天与人格

- 内置人格“顾清影”（英文名 Selene）：安静时清冷、聊开了活泼，口语化、会斗嘴也会心疼人（人格文件 `src/prompts/gqy.md`）。面向所有用户：你们是什么关系、她怎么称呼你，按用户资料（新手引导「认识你」或设置里的「用户身份」）来，资料里写明是恋人才会撒娇，否则是熟络的朋友。
- 可以新建**多个人格**（persona）和**用户身份**（identity），按会话/QQ 群/平台切换。
- 带示例对白（`gqy-dialogs.md`）和可选的“人格提醒”（persona reminder）。

### 日常信息

| 能力 | 数据来源/说明 |
|---|---|
| 天气 | Open-Meteo 六类查询（预报/空气/历史/海洋/气候/海拔），失败回退 wttr.in；中文摘要 |
| 汇率 | exchangerate-api 付费源，失败可回退免费源 |
| 网络搜索 | Tavily、Firecrawl、AnySearch、Exa、SearXNG 任配；没配也有 Exa 免 key 额度 + DuckDuckGo/Yahoo/360/搜狗爬虫回退链 |
| 网页阅读 | 抓取 URL，转 Markdown/纯文本/HTML，5 MiB 上限 |
| 搜图 | SearXNG/DDG/Bing/百度/360 多源并行，视觉模型筛选安全与相关性 |
| 识图 | 本地图片或 QQ 图片，调用多模态模型描述内容 |
| 生图 | OpenAI 兼容生图 API（插件默认关闭，需配置） |
| 剪贴板 | 读取文本/图片（wl-paste/xclip/xsel） |
| 当前环境/主机信息 | check_os_info、host-environment 信息注入 |

### 桌面 Linux 日用

- **Arch Linux**：Arch Wiki 查询、官方包查询、AUR 搜索/详情/状态、Arch 新闻。
- **AUR 安全**：审查 PKGBUILD（风险 high/medium/low），确认后才帮装 AUR 包。
- **Linux 游戏兼容性**：综合 ProtonDB + Are We Anti-Cheat Yet? + Can I Play On Linux，给结论和建议。
- **输入法排障**：可查 Fcitx5 wiki。
- **man 手册**：在线查询 man.archlinux.org 和 man7.org。
- **命令执行**：顾清影 可以在终端里帮你跑命令（有超时、输出限制、命令黑名单）。

### 办公与开发

- **文件操作**：读文件、glob 找文件、grep 搜索、写文件、精确字符串编辑、统一 diff 补丁（apply_patch）。
- **计算**：自带科学计算器（sin/cos/ln 等函数，弧度制）；哈希/Base64/Hex/Rot13 编解码。
- **Todo**：会话级 todo 列表，AI 复杂任务前会自己建。
- **后台任务**：`background=true` 让命令或子代理在后台跑，前端退出任务继续（daemon 负责）。
- **子代理 task**：explore/general 两种子代理，可指定 cheap/balanced/strong 档位模型，带超时、重试、checkpoint。
- **MCP**：可配置 stdio MCP server，其工具自动注册成 顾清影 工具。
- **Artifact**：WebUI 里 AI 产出文件，可预览、复制、下载，还能继续改。
- **Dev 模式**：极简工具集，专注写代码。

### 生活娱乐

- **闹钟**：`“20 分钟后叫我”`、`“13:45 提醒我泡面”`；独立子进程保证到点响（内置音频或自定义 mp3/wav）。
- **记账**：`“中午吃饭花了 3000 日元”` 就记下了；支持多本账（工作/生活分开）、账户与两级分类、月度预算。外币按当日汇率自动换算成账本币种，汇率连同来源冻结在账目里、永不重算；取不到汇率时账照记、标为待换算，绝不拿猜的数字凑合计。超预算时她记完会顺口告诉你。WebUI 控制台有完整看板，可 CSV 导入导出。只在终端 / WebUI 可用，QQ 侧不注册。
- **重复提醒**：连续重复调用同一工具时，第 3/5/8 次会温和/详细提醒。
- **玄学**：周易六十四卦、吉凶占、塔罗牌、投骰子（只是娱乐/心理学）。
- **表情包**：聊天时按概率自动发；可搜索/添加/删除表情，自带 30+ 张 顾清影 表情。
- **图库**：`“把这张留着”` 就存进按人格分的相册；按名称/描述/标签找回来并发出。与表情包分开——表情包是「该有反应时自动挑」的，塞非表情包进去会污染那套挑选。WebUI 控制台有面板可上传、改描述、删除。
- **地图**：`“上海图书馆东馆在哪”` 给的是一张带标记点的真地图卡片（可拖可缩，点开有详细视图），不是一条外链。默认走开源的 OpenStreetMap，配了高德 Web 服务 Key 自动切高德；瓦片由 daemon 代取并缓存，浏览器不与瓦片服务器直接说话。
- **快递查询**：单号查物流轨迹，WebUI 渲染成时间线卡片。需要快递 100 的 Key；没配时她会直说查不到并给官方入口，不会编一条像模像样的轨迹。
- **闲鱼搜索**：内置脚本搜索二手市场（依赖 playwright/Chromium）。
- **macOS 日用**（仅 macOS）：内置 `macos_reminders` 脚本读写「提醒事项」待办，`macos_news` 汇总 macOS 更新与安全公告（相当于 Arch 新闻的 macOS 版）。
- **体脂秤**：内置 `afu_scale` 脚本经蓝牙读取蚂蚁阿福体脂秤的体重与体成分。
- **Blender 建模**：内置 `blender_model` 脚本驱动 Blender 建模、执行 bpy 代码、导出与渲染。
- **周易起卦**：内置 `iching_divination` 脚本按铜钱法起卦，给出本卦、变爻和之卦。
- **游戏破解状态查询**：内置脚本查 crackrelease/isitcracked。
- **进程占用**：内置 `procusage` 脚本查 CPU/内存排名。
- **电池管理**：内置 `battery-care` 脚本查/改笔记本充电阈值。
- **动漫百科**：萌娘百科查询。

### 记忆与知识

- **记忆系统**：短期日记、长期日记、知识点三类；自动写日记、后台整理、联想召回、遗忘衰减。
- **记错会改**：你纠正过她的事，她连同原因记成一条「纠正」记忆，下次不再犯；终端 / WebUI 的对话安静一阵后，她会在后台复盘这段对话，下一轮起按复盘结果调整（`plugins.memory.review_idle_seconds`，默认 900 秒，0 关闭）。
- **知识库**：自带「顾清影使用手册」（来自仓库 `kb/`，她被问到怎么用自己时会查）；可 `gqy kb add` 增删改查；可选 embedding 语义检索。
- **skills**：内置 `skill-creator`、`script-creator`（教她怎么扩展自己）、`gqy-cli`（她自己的命令行手册）、`webui-theme`（给 WebUI 写配色主题）和 Linux 游戏兼容性调查技能；用户可写新 skill。
- **脚本**：扩展目录放带头部注释的可执行脚本，AI 就能调用；头部可写 `# Platform: macos|linux` 只在对应系统上注册。
- **扩展管理**：WebUI「控制台 → 设置 → 插件」底部的「扩展」分组列出技能、脚本工具、MCP 服务器和 pm 包，可开关、看详情、新建技能；从 GitHub 克隆来的扩展能检查更新并一键更新（同时同步 npm/uv/pip 依赖），pm 包能升级和卸载（安装仍用 `gqy pm install`）。`gqy config` → 插件配置 → 扩展 是终端版（只列表和开关）。

### 多端与远程

- **终端**：REPL、一次性提问、fish/zsh/bash 无缝集成。
- **WebUI**：局域网网页，手机/平板也能用；「界面 → 配色方案」可换主题（内置默认、壁纸取色，以及她用 `webui-theme` 技能写进 `~/.gqy/config/webui-themes/` 的 CSS 主题）。
- **QQ**：OneBot/NapCat 接入，私聊远程操作电脑、群聊陪聊 + 群管理；资料卡点赞、回复贴表情、群聊黑名单、主动私聊等都是可开关的插件。
- **iMessage**（仅 macOS）：daemon 的连接器平台（`platforms.connectors.imessage`），配合仓库里 `scripts/imessage/` 的连接器脚本，名单内联系人私聊，手机上可用 `/new`、`/topics`、`/model`、`/pause` 等指令，见 `scripts/imessage/README.md`。
- **GitHub bot**：`gqy github login` 给她登录一个自己的 GitHub 账号，`github` 工具里明确要求时用它提交、开 PR / issue。
- **`tool-call` 工具桥**：让 shell 脚本以当前会话身份调用 顾清影 工具。
- **桌面通知**：回合完成等事件可通知（notify-send/osascript/PowerShell）。

### 运维与数据

- **daemon**：统一后台服务，WebUI/QQ/后台任务都住在里面；`gqy daemon status|logs|restart`。
- **日志**：按天滚动 8 份；`--debug` 详细诊断；`daemon logs request` 录制出网请求。
- **用量统计**：请求数、token、缓存命中、费用估算（usage.json + 明细）。
- **导出/导入**：`gqy export` 打成 tar.gz，`gqy import` 还原到新机器。
- **缓存优化**：前缀缓存友好设计，长会话可达到九成以上缓存命中。

## 一句话总结

> 普通模式 = 能陪你聊天的二次元 AI + 日用工具全家桶；开发模式 = 摘掉人格的极简编码助手。两者共用一套 daemon、会话数据库和工具框架，但配置与记忆隔离。
