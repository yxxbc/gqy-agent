# 11 · 数据与目录

> ⚠️ **临时版本提示**：本文档由 DeepSeek 根据当前 顾清影 源码逐行整理，属于临时参考版本；正式版文档仍在施工中，内容可能与最新代码存在出入。请以 `gqy -h`、`gqy config`、仓库 README 及源码为准。

## 1. 根目录：`~/.gqy`

默认一切都在 `~/.gqy`（`GQY_HOME` 可改）。目录权限都是 0700（只有你自己能进）。

```text

├── config/                       系统配置（/etc）
│   ├── config.jsonc              主配置（JSONC，允许注释）
│   ├── dev-prompt.md             开发模式提示词
```

实际路径可用 `gqy paths` 打印，`gqy layout` 看布局与搬家计划。没有 `.home-layout-v1` 标记的是老布局：会话库在 `state/`，人格/技能/脚本/身份/图片/文档/账本/分享都在 `data/` 下；升级后 daemon 首次启动自动搬（见 [12-备份迁移与更新](12-备份迁移与更新.md)）。

## 2. 系统级目录（打包安装）

程序在「二进制所在目录/../share/gqy/」下找资源（预编译包、Nix store、`install.sh` 都是这个布局）；Linux 另认 `/usr/share/gqy/`，debug 构建再回退到源码树。每类都有环境变量可覆盖（`src/paths/resources.rs`）。

| 路径（相对安装前缀） | 内容 | 覆盖变量 | 缺失时的表现 |
|---|---|---|---|
| `share/gqy/fonts/` | Noto CJK + Color Emoji + JetBrains Mono | `GQY_RENDERER_FONTS_DIR` | QQ 长回复转图退化为纯文本 |
| `share/gqy/models/` | 内置嵌入模型 `bge-small-zh-v1.5-int8` | `GQY_EMBEDDING_MODELS_DIR` | 语义检索退回关键词 |
| `share/gqy/default-kb/` | 默认知识库（本仓库 `kb/`） | `GQY_DEFAULT_KB_DIR` | 默认知识库为空 |
| `share/gqy/scripts/` | 内置脚本 | `GQY_SYSTEM_SCRIPTS_DIR` | 无内置脚本 |
| `share/gqy/memes/` | 系统表情库（当前发布包不带） | `GQY_MEMES_DIR` | 只用用户表情库 |

## 3. 数据库要点

- 主库 `conversation.db` 使用 WAL、busy_timeout 5s、外键开启；迁移到 v37，每个迁移在 immediate 事务里做并跑 FK check。
- 账本 `home/<管理员>/ledger/ledger.db`（老布局 `data/ledger/ledger.db`）是独立库，不挂主库：主库每轮对话都在写，账本一天几笔，而 SQLite 损坏几乎都发生在写入过程中——写得越少越安全，主库真出事时账本也不陪葬。它用 `synchronous=FULL`（吞吐无所谓，断电不丢刚记的账），打开时跑 `quick_check`，迁移前用 `VACUUM INTO` 备份成 `ledger.db.bak`。
- **不要**在 daemon 运行时直接删/改 DB；先 `gqy daemon stop`。
- 旧版本迁移到 `~/.gqy` 时：旧 XDG 目录里的 config/data/cache/state 会被搬过来；`Documents/Miyu` → `data/documents`；`Pictures/gqy`、`Pictures/Miyu` → `data/pictures`。
- 迁移前会两遍预检，失败零写入；符号链接、跨文件系统等危险情况会拒绝或丢弃缓存。

## 4. 运行期目录

- IPC socket：`$XDG_RUNTIME_DIR/gqy/core.sock`；没有 XDG_RUNTIME_DIR 时回退 `state/gqy`。
- 锁文件：`core.lock`（daemon/web 单实例）、`starter.lock`（启动互斥）。
- 权限：socket 目录 0700、密码文件 0600。

## 5. 日志

| 文件/流 | 内容 |
|---|---|
| `cache/logs/gqy.*.log` | 按天滚动 8 份；默认 ERROR，QQ 日志 INFO |
| `cache/logs/daemon.log` | daemon 启动 banner/panic 等非结构化输出 |
| `cache/logs/cache-usage.<date>.jsonl` | 每请求 token 绝对值（默认开，保留 14 天） |
| `cache/logs/requests-<date>.jsonl` | 完整请求体（默认关，`GQY_LOG_REQUESTS=1`） |
| `cache/logs/alarm.log` | 闹钟 worker 日志 |

`--debug` 把主日志提到 DEBUG。`daemon logs request` 是进程内存开关，不落配置。
