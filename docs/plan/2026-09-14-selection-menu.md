## 2. 设计

### A. 触发与退路

- **只在聊天消息正文**(`.markdown-body`)里、且选区非空时拦截;其他地方、没选中文字时一律原生菜单。
- **Shift + 右键 = 原生菜单**,菜单底部写一行提示。拦截原生菜单不能把用户的退路也拿走。
- 我们的菜单**必须自带「复制」**——原生菜单被替掉之后,最常用的就是它。
- 键盘:`Esc` 关闭,方向键移动,`Enter` 执行。
- 手机:iOS 的长按菜单拦不住,也不该拦。选区稳定后(`selectionchange` 停 300ms)浮一条小工具条,项目同上。施工时放在选区下方,原因见 §6。

### B. 四个菜单项

| 项 | 做什么 | 走不走模型 |
|---|---|---|
| **解释** | 结合本回合上下文解释选中内容 | 旁路请求 |
| **翻译** | CJK 占多数译成英文,否则译成中文;浮窗里可切换目标语言 | 旁路请求 |
| **引用追问** | 把选中文字以 `> 引用` 插进输入框并聚焦,用户接着打字 | 不走,纯前端 |
| **搜索** | 用选中文字搜索,结果列表进浮窗 | 知识库走现有接口,网页走新接口(§4 裁定:两栏都列) |

### C. 解释 / 翻译接口

`POST /api/selection/assist {session_id, turn_id, action: "explain" | "translate", text, target_lang?}` → 流式返回。

- **上下文由后端按 `turn_id` 从库里取**,不收前端传来的「用户问了什么 / 她答了什么」:
  - 用户侧取 `raw_content`,她那侧取展示内容——正是理念「三份内容分离」里给人读的那两份,不带工程附加物。
  - 前端传上下文的话,等于任何人都能拼一段「她说过的话」喂给模型。
- **会话归属校验**:成员只能对自己的会话发起。
- 长度上限:选区 ≤ 2k 字;上下文两侧各 ≤ 8k 字,超了保留头尾。数字施工时按旁路档位的窗口定。
- 新增 `AuxRole::SelectionAssist`(配置键 `selection_assist`),缺省档位 `lite`;设置页「旁路请求」卡片多一行「划词解释 / 翻译」。
- `with_request_scope("selection-assist")`:独立记账,不算进主对话缓存(AGENTS.md §1.7)。
- 提示词是**常量英文短句**(AGENTS.md §1.5),选区与上下文装进 XML 标签外壳;输出语言跟随用户。
- 浮窗关闭即中断流,不在后台白跑。

### D. 浮窗

- 锚在选区矩形旁,放不下自动翻到另一侧;手机上变底部弹出面板。
- 流式出字,内容走现有纯 DOM `renderMarkdown`,不开 HTML。
- 操作:**复制 · 重试 · 钉住 · 转成追问**(把「引用 + 解释」一起塞进输入框)。
- 钉住后可以再选别的词开第二个浮窗;未钉住的点外部即关。
- 按住标题栏可拖动,拖过即自动钉住(2026-09-14 看预览后追加,见 §6)。
- **不进对话、不进记忆和日记、不落库。**

### E. 搜索

- 知识库:复用 `/api/dash/kb/search`。已核实(见 §6):按账号取各自的知识库,成员只搜得到自己的。
- 网页:没有现成 HTTP 接口,要新开一个,复用 `web_search` 工具背后的同一个搜索实现,不另写抓取。
- 结果列表进浮窗:网页结果点开新标签;知识库结果点开进侧栏预览(与 `../../plan/2026-09-14/file-links.md` 的侧栏临时视图同一槽位)。

## 3. 理念对照

| 理念 | 落到这里 |
|---|---|
| 前缀即契约 · 三份内容分离 | 解释结果不进主对话上下文,主对话前缀一个字节不动;旁路请求独立 scope |
| 权限由代码承担 | 上下文后端取、会话归属后端判;前端没有能力伪造「她说过的话」 |
| 文风规范 | 旁路提示词常量英文,不拼时间戳;选区与上下文是不可信文本,装在标签里 |
| 报错要说真原因 | 旁路档位没配模型时直接说「设置 → 模型池 → 旁路请求 → 划词解释 没有可用模型」,不说「请求失败」 |

## 4. 裁定(2026-09-14)

1. 解释用**中性说明**,不带人格提示词。
2. 搜索**知识库与网页两栏都列**,知识库在前。
3. 结果**不留历史**。
4. 侧栏里的选区**先不做**。
