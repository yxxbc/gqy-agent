# 记忆怎么查看、修改和清空

她会把聊天里值得记住的事存成长期记忆，下次聊到相关话题时自动想起来。记忆按人格分开存，开发模式不带记忆。

## 让她记住或忘掉

直接说就行：「记住我对花生过敏」「你记错了，我是周四开会」。你纠正过她的事，她会连同原因一起记下来，下次不再犯。

## 查看和管理

- **网页端**：记忆面板能按类型浏览，也能搜索，单条删除或勾选后批量删除。「经历」页是她整理过的经历，「复盘」页是聊后复盘的结果（只读）。
- **命令行**：
  - `gqy memory search <关键词>`：搜索记忆；
  - `gqy memory stats`：记忆统计；
  - `gqy memory remember <内容>`：手动存一条。

## 聊后复盘

终端或网页端的对话安静一段时间后，她会在后台回顾这段对话，记下最多 3 条下次要注意的地方。等待时长在「设置 → 记忆」里改（默认 900 秒），设成 0 就关掉。

## 清空

从轻到重：

- `/reset-memory`（或 `gqy reset-memory`）：只清空这个会话里记下的长期记忆。
- `/reset-all-memory`（或 `gqy reset-all-memory`）：清空当前人格的全部长期记忆。
- `/wipe`（或 `gqy wipe`）：抹掉记忆、所有会话内容和群聊上下文，技能和脚本会保留。

清空前建议先 `gqy export` 备份。

## 和会话历史的区别

会话历史是聊天记录本身，记忆是从聊天里提炼出来、跨会话都能用的事实。删会话不会删记忆，清记忆也不会删会话。
