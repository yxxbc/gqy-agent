# 第一次打开要做什么

在终端输入 `gqy`。第一次打开会进入新手引导，五步走完就能聊，每一步点「下一步」时就保存了：

1. **选人格**：用内置的顾清影，或者自己捏一个（起个名字，人格设定可以留空）。
2. **选功能**：勾选想要的插件，比如图库、地图、快递、记账。
3. **认识你**：告诉她怎么称呼你、你是做什么的、你们是什么关系。她对你的称呼和相处方式都按这里写的来。
4. **终端集成**：可选。装上之后在 shell 里就能直接和她说话，不用进对话界面。
5. **接模型**，三种方式任选：
   - 借用你已有的 Claude Code、Codex 或 Antigravity 订阅；
   - 选 opencode Zen，勾上「使用公共密钥的免费额度」，不用填 key 就能先试；
   - 选一个供应商，填你自己的 API key。

想重新走一遍引导：`gqy oobe`。之后改任何设置都用 `gqy config`，或者在对话里输入 `/config`。

## 两种模式

- `gqy`：普通模式。有性格、有记忆，能闲聊、查天气汇率快递、看地图、生成图片、定时提醒。
- `gqy dev`：开发模式。收起人格和生活工具，只留写代码需要的东西。

空会话（还没说过话）时按 `Tab` 在两种模式之间切换。一旦开始对话，这个会话的模式就固定了。

## 推荐的终端

推荐 Kitty：图片能直接显示在对话里。时间线上的图标用的是 Nerd Font 字形；终端没装 Nerd Font、图标显示成方块时，设置环境变量 `GQY_TUI_ASCII=1` 改用通用符号。
