# 怎么开启和使用语音

语音识别在本机完成，录音不上传。

## 前提

预编译包和 Nix 包都不带语音组件 `gqy-voice`，需要从源码编译带语音的版本：在项目仓库里运行 `cargo install --path . --locked --features voice`。`gqy` 和 `gqy-voice` 要放在同一个目录（这条命令会一起装到 `~/.cargo/bin`），后台服务启动时会在 `gqy` 旁边找它。

## 开启

`gqy config` →「语音功能」里打开。开启后后台服务会自动拉起语音进程。

## 用法

- **唤醒**：喊唤醒词，默认是「清影清影」或「顾清影」。听到提示音、看到桌面通知后说出你的要求，她办完会播报回复摘要。唤醒词在语音设置里可以改。
- **听写**：在对话界面输入 `/stt`，或在网页上点麦克风，说的话会填进输入框。命令行 `gqy stt` 说一句话直接当消息发出去。
- **快捷键收听**：`gqy listen` 让她立刻开始听，不用喊唤醒词。把这条命令绑到桌面快捷键上最方便。

## 语音相关命令

- `gqy voice status`：语音进程的状态。
- `gqy voice say <一句话>`：用当前的语音合成设置播一句话，用来试听。
- `gqy voice history`：语音对话最近的记录。
- `gqy voice reset`：清空唤醒对话用的专属会话，下次唤醒重新开始。

语音合成（她说话的声音）可以接 MiniMax 或小米 MiMo，在语音设置里选。

## 喊了没反应

- 先看 `gqy voice status`，确认语音进程在跑、麦克风能用。
- macOS 要在「系统设置 → 隐私与安全性 → 麦克风」里给终端或 gqy 授权。
- 「影」字喊成二声也能唤醒，默认把两种读音都注册了。还是不灵的话，可以在语音设置里调唤醒灵敏度。
