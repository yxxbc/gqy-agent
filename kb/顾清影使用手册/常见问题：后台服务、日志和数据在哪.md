# 常见问题：后台服务、日志和数据在哪

## 后台服务

顾清影有一个常驻的后台服务（daemon），负责跑对话、网页端、通讯平台和语音。打开 `gqy` 或 `gqy web` 时会自动启动它。

- `gqy daemon status`：看后台服务和各个接口（网页端、QQ 等）的状态。
- `gqy daemon restart`：重启。改了设置不生效、界面卡住时先试这个。
- `gqy daemon stop` / `gqy daemon start`：停止 / 启动。
- `gqy daemon logs`：持续查看日志，排查问题时用。
- `gqy reload`：让后台服务重新读一遍配置，不用重启。

升级程序后，下次打开 `gqy` 时后台服务会自动换成新版本。

## 数据和配置在哪

- 全部数据都在 `~/.gqy`。`gqy paths` 列出配置、数据、缓存、日志各自的具体位置。
- 配置文件是 `~/.gqy/config/config.jsonc`。建议用 `gqy config` 或网页端设置页改，不要手改。改完可以用 `gqy config validate` 检查格式。

## 常见情况

- **打开 gqy 卡住或报错连不上**：`gqy daemon restart`，还不行就看 `gqy daemon logs`。
- **时间线上的图标显示成方块**：终端没装 Nerd Font。装一个 Nerd Font，或者设置环境变量 `GQY_TUI_ASCII=1` 改用通用符号。
- **浅色终端下颜色看不清**：`gqy config` →「全局参数设置」→「终端底色」选「浅色」。默认是自动检测。
- **提示默认知识库需要更新**：运行 `gqy update-default-kb`。
- **她说自己查过、实际没查**：告诉她「你没查」，她会承认并记下来。她是按规则只说真正调用过工具才得到的结果，这种情况多半是模型本身的问题，换一个更强的模型通常会好。

## 反馈问题

到项目仓库 `yxxbc/gqy-agent` 提 issue，附上 `gqy daemon logs` 里相关的几行和你的系统版本。这是业余维护的个人项目，会尽力回复，但不保证时效。
