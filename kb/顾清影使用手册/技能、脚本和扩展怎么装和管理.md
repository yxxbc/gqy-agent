# 技能、脚本和扩展怎么装和管理

不改程序就能给她加本事，一共四种：

- **技能**：一篇写给她看的做事说明，比如「怎么写周报」。她觉得用得上时才加载。
- **脚本工具**：一个可执行脚本，注册后她就能像用内置工具一样调用。
- **MCP 服务器**：外接的工具服务，接上后它提供的工具她都能用。
- **pm 包**：别人打包好的一组技能和脚本，用 `gqy pm` 安装。

## 最简单的办法：直接跟她说

- 「帮我写个技能，以后写周报按这个格式来」，她会自己建技能。
- 「写个脚本帮我查 xxx」，她会写好脚本并注册成工具。

## 在网页端管理

「控制台 → 设置 → 插件」，拉到底部的「扩展」：

- 技能、脚本工具、MCP 服务器、pm 包分组列出，每项都能开关，点开看详情。
- 技能和脚本的开关马上生效；MCP 的开关要点「保存配置」。MCP 服务器的添加和修改在「设置 → MCP」页。
- 「新建技能」：填名字（小写字母、数字、连字符）、一句话说明（她靠这句判断什么时候用）和正文。
- 每项会标来源：来自 GitHub、来自 pm 包、自己创建、内置、其他程序管理。
- 从 GitHub 克隆来的扩展可以「检查更新」「更新」，更新时会顺便装好它需要的 npm / Python 依赖。你自己改过还没提交的，不会被覆盖。
- pm 包可以在这里升级和卸载。安装要下载外部代码，只能用命令行。

终端里 `gqy config` →「插件配置」→ 最后一行「扩展」也能看列表、开关技能和脚本。

## 命令行

- 技能：`gqy skills list`、`gqy skills show <名字>`、`gqy skills enable/disable <名字>`、`gqy skills remove <名字>`。
- pm 包：`gqy pm install owner/repo`、`gqy pm list`、`gqy pm upgrade [名字]`、`gqy pm remove <名字>`、`gqy pm search <关键词>`。

## 内置的技能和脚本

- 内置技能：`skill-creator`、`script-creator`（她给自己加技能、写脚本时用）、`gqy-cli`（她自己的命令行手册）、`webui-theme`（给网页端写配色主题）、`linux-game-compatibility`（查游戏能不能在 Linux 上玩）。
- 内置脚本有天气、占卜、周易起卦、计算器、编解码、萌娘百科、闲鱼搜索、游戏破解状态、进程占用、电池管理、AnySearch 搜索、Blender 建模、蚂蚁阿福体脂秤等；macOS 上还有「提醒事项」待办和 macOS 更新公告。只适用于某个系统的脚本，在别的系统上不会出现。
- 换成自己捏的人格时，内置脚本和大部分内置技能默认不挂，要在新手引导的「功能」一步或人格设置里勾上。
