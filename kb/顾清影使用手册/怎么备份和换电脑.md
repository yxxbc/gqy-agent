# 怎么备份和换电脑

所有数据都在 `~/.gqy`：配置、会话、记忆、知识库、图库。

## 导出

```bash
gqy export                 # 配置、会话、记忆和知识库原文，文件名按主机名和时间自动生成
gqy export 备份.tar.gz      # 指定文件名
gqy export --no-secrets    # 不含 API key 和访问令牌，适合分享给别人
gqy export --dry-run       # 只看会打包什么、有多大，不真的写
gqy export --all           # 连知识库向量索引和通讯平台聊天记录一起打包
```

默认的备份文件里有明文的 API key 和令牌，请妥善保管，不要上传到公开的地方。

## 导入到新电脑

先在新电脑上装好顾清影，然后：

```bash
gqy daemon stop                       # 先停掉后台服务
gqy import gqy-export-xxx.tar.gz      # 导入
```

新电脑上已经有数据时要加 `--force` 覆盖，覆盖前会先自动备份当前的数据。

用 `--no-secrets` 导出的备份，导入后要重新填 API key。知识库的向量索引没打包的话，可以用 `gqy kb embed` 重建。
