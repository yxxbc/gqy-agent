# 会话怎么新建、切换和清理

每个会话是一段独立的对话，有自己的上下文和模型设置。

## 在对话界面里

- `/new [名字]`：新建会话并切换过去。名字可以不填，第一条消息会自动起名。
- `/session`：列出会话，选一个切换过去；在列表里按 `Ctrl+D` 删除选中的会话。也可以 `/session 名字` 或 `/session 序号` 直接切。
- `/rename <名字>`：重命名当前会话。
- `/delete [名字或序号]`：删除会话，不带参数删当前会话。
- `/reset`：清空当前会话，重新开始。
- `/undo`：撤销上一轮对话，或撤销上一次上下文压缩。
- `/compact`：立即压缩上下文。聊得很长时，把早先的内容压成摘要，省 token，也能继续聊。
- `/pop [轮数]`：把最早的几轮移出当前上下文。
- `/history`：显示最近的会话历史。
- `/usage`：查看 token 用量。

输入 `/` 会列出所有命令，`/help` 看完整说明。

## 命令行

`gqy session` 下有 `list`、`new`、`show`、`delete`、`rename`、`clear`、`compact`、`models` 等子命令，和上面一一对应。`gqy session show` 能看到会话的模式、轮数和上下文占用。

## 上下文快满了怎么办

底栏右边显示上下文占用，比如 `47k/168k ▰▱▱▱▱ 28%`。占用条变黄、变红时，说明快满了。满了之后默认会自动压缩，也可以提前手动 `/compact`，或者 `/new` 开一个新会话。
