# 怎么安装、升级和卸载顾清影

顾清影支持 Linux（x86_64 / ARM64）和 macOS（Apple 芯片 / Intel），不支持 Windows。

## 安装

**有 Nix（推荐）**：

```bash
nix profile install github:yxxbc/gqy-agent/gqy
```

下载的是云端编译好的程序，不用本地编译，不需要 root。Intel Mac 不在 Nix 支持范围内，请用下面的一键脚本。只想先试试：`nix run github:yxxbc/gqy-agent/gqy`。

**没有 Nix，或者是 Intel Mac**：

```bash
curl -fsSL https://raw.githubusercontent.com/yxxbc/gqy-agent/gqy/install.sh | sh
```

装到 `~/.local`，不需要 root。安装时有进度条；只想看看安装界面、不真的安装，在命令后面加 `sh -s -- --preview`。提示 `~/.local/bin` 不在 PATH 里时，把 `export PATH="$HOME/.local/bin:$PATH"` 加到 `~/.zshrc` 或 `~/.bashrc`，再重新打开终端。

装指定版本：`GQY_VERSION=v0.6.0`；装到别的目录：`GQY_PREFIX=/opt/gqy`，这两个环境变量写在 `sh` 前面。

## 语音组件

预编译包和 Nix 包都不带语音组件 `gqy-voice`。要用语音，目前需要从源码编译：`cargo install --path . --locked --features voice`（在克隆下来的项目仓库里运行）。

## 升级

- Nix：`nix profile upgrade gqy-agent`，升级后有问题可以 `nix profile rollback` 退回上一版。
- 一键脚本：再运行一次安装命令。

每个版本更新了什么，见项目仓库的 CHANGELOG.md。

## 卸载

先停掉后台服务：`gqy daemon stop`。

- Nix：`nix profile remove gqy-agent`
- 一键脚本：删除 `~/.local` 下的 `bin/gqy`、`lib/gqy`、`share/gqy`、`share/licenses/gqy`

卸载只删程序。配置、会话、记忆和知识库都在 `~/.gqy`，要彻底清除就把它也删掉，删之前建议先 `gqy export` 备份一份。
