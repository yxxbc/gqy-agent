# 怎么在浏览器和 shell 里使用

## 浏览器（网页端）

```bash
gqy web
```

会打印局域网地址（默认端口 8300），同一 Wi-Fi 下的手机、平板也能打开。

- 第一次登录用内置账号（用户名 `gqy`，密码 `GQY520`），登录后会让你创建自己的管理员账号，建好后内置账号自动失效。
- 管理员可以在控制台的「账号」页生成邀请码，请朋友注册。每个人的会话和记忆互相隔离。
- 网页端能做的：聊天、上传附件、切换模型（输入框里的模型按钮）、看上下文占用（输入框里的小圆环，点开看明细）。
- 左下角「控制台」里是各种面板：数据统计、账号、记忆、知识库、表情包、图库、记账；管理员还有平台（QQ 设置）、好感·情绪、脚本和设置。
- 所有设置都在「控制台 → 设置」里，分成界面、人格、供应商、模型池、全局、MCP、插件、高级几页。
- 选中聊天里的一段文字再右键，可以让她解释、翻译或引用追问。

## 换网页端的配色

「控制台 → 设置 → 界面 → 配色方案」里选：「默认」、「壁纸取色」（按桌面壁纸自动配色，需要装 matugen），以及你自己的主题。

想要新主题，直接跟她说想要什么样子，比如「给网页端做一套深蓝色、圆角小一点的主题」。她会写一个 CSS 文件放进 `~/.gqy/config/webui-themes/`，刷新配色方案列表就能选。主题只能改颜色、字体、圆角这类样式，不能改页面功能。

## 端口和访问范围

只想本机访问：`gqy web --bind 127.0.0.1`。换端口：`gqy web --port 9000`。

## shell 里直接问

装上终端集成后，在命令行里就能直接用自然语言和她说话，不用进对话界面：

```bash
gqy zsh-init     # 或 gqy bash-init / gqy fish-init
```

fish、bash、zsh 都支持。不想要了：`gqy remove-shell-hook`。

不装集成也能一次性提问：

```bash
gqy "今天杭州天气怎么样"
gqy ask "帮我解释一下这个报错" < error.log
```

终端集成用的是一个单独的「终端会话」，有自己的一套命令：`gqy history` 看历史，`gqy reset` 清上下文，`gqy models` 换模型。
