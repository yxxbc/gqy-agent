# 怎么换模型和供应商

## 在对话里临时换

- `/models`：列出可用模型并切换**当前会话**用的模型。也可以直接带参数：`/models 3`（序号）、`/models 供应商/模型名`，`/models default` 恢复跟随全局设置。
- `/variant`：查看或切换思考档位（模型支持时才有，比如深度思考的高低档）。

只影响当前这个会话，别的会话不变。

## 改全局设置

`gqy config` →「供应商和模型」：

- 添加或修改供应商、填 API key、选模型；
- 「配置全局文本模型」「配置全局多模态模型」：没有单独设置过的会话（包括网页端和通讯平台）都用这里的模型；
- 「配置 Embedding 模型」：知识库按意思检索时用；
- 「配置分级模型池」：把模型分成 lite / cheap / standard / flagship 几档，不同任务按档位挑模型。

网页端在「控制台 → 设置」的「供应商」和「模型池」两页里改同样的内容；聊天时点输入框里的模型按钮，可以只给当前会话换模型。

## 命令行

- `gqy list-models`：列出可用模型。
- `gqy models <序号或供应商/模型名>`：改终端集成会话用的模型；加 `-g` 改的是全局模型池。
- `gqy session models`：查看或设置某个会话的模型覆盖。

## 能接哪些模型

兼容 OpenAI / Anthropic 协议的服务都能用，也能借用 Claude Code、Codex、Antigravity 的订阅。没有 key 可以先用 opencode Zen 的公共免费额度试。免费额度不稳定，长期用建议配置自己的 API key。
